# Memory-Card
Программа 'Memory card' создана для изучения и запоминания различной информации в формате вопрос-ответ.
Из списка вопросов выбирается один с четырьмя вариантами ответов: 1 правильный, остальные - нет.
Не зависимости от ответа после вопроса будет написано его правильный вариант. 
Также после ответа на первый вопрос появится счётчик вопросов и правильных ответов. Также появляется рейтинг, его число меняется в зависимости от среднего арифметического числа всех вопросов и правильных ответов. Отвечая правильно - рейтинг растёт, отвечая неправильно - рейтинг падает.
